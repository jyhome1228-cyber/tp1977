# TAEPYUNG PAPER Website

태평제지 공식 웹사이트의 GitHub Pages 이전 프로젝트입니다.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Structure
- `/index.html` — Home
- `/company/` — 개요
- `/business/` — 운영현황
- `/product/` — 제품소개
- `/esg/` — 지속가능경영
- `/recruit/` — 채용
- `/contact/` — 고객만족
- `/privacy/` — 개인정보처리방침
- `/assets/css/style.css` — 공통 스타일
- `/assets/js/layout.js` — 서브페이지 공통 헤더/푸터
- `/assets/js/main.js` — 메뉴/스크롤/리빌 인터랙션

## Production domain
`www.tp1977.com`

## Migration notes
1. 현재 버전은 기존 아임웹 사이트의 사이트맵과 핵심 텍스트를 기반으로 재구성한 1차 정적 사이트입니다.
2. 기존 제품/회사 이미지 파일은 다음 단계에서 `/assets/images/`로 이관합니다.
3. 문의·채용 폼처럼 서버 처리가 필요한 기능은 별도 백엔드 또는 폼 서비스 연동이 필요합니다.
4. 도메인 DNS 변경은 신규 사이트 검수 후 진행합니다.
